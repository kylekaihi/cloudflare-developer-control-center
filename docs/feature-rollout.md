# 功能扩展路线

本轮按“先减少人工维护，再提高告警准确性，最后扩大监控范围”的顺序实施。

## 第一批：运维基础能力

- [x] 服务自动发现与卸载清理：支持只展示当前运行中的 Docker 容器，并保留显式健康检查配置。
- [x] 自定义告警规则：CPU、内存、磁盘和服务故障阈值通过环境变量配置。
- [x] 维护模式：按节点或服务设置时间窗口，窗口内抑制告警和通知。

## 第二批：外部可用性

- [ ] HTTP/HTTPS 域名探测：状态码、延迟和连续失败告警。
- [ ] TLS 证书到期检查：记录证书剩余天数并提前告警。

## 已有能力

- 部署版本、Git Commit 和部署变更事件已经由 Status API 与 D1 记录，并在 Dashboard 的“部署版本”区域展示；后续只需增强筛选和发布历史查询。
